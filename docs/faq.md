# 常見問題

## 網頁版和桌面版

### 我該用網頁版還是桌面版？

入門教學全部可以用**網頁版**完成，不用安裝任何東西。需要處理大型資料、匯出高解析度地圖，或用到網頁版沒有的功能時，再安裝**桌面版**。

| | 網頁版 | 桌面版 |
|---|---|---|
| 安裝 | 不用，打開 [web.rustgis.app](https://web.rustgis.app) | 要下載安裝 |
| 資料 | 只在你的瀏覽器裡處理，不會上傳 | 在你的電腦上處理 |
| 開啟檔案大小 | 電腦上的檔案最大 512 MB；網址最大 256 MB | 可以處理更大的檔案，依電腦記憶體而定 |
| 從網址開啟資料 | 對方伺服器要允許跨域讀取（CORS） | 沒有這個限制 |
| 儲存專案 | 下載一個 `.rgis` 檔到「下載」資料夾 | 存在你選的位置 |
| 匯出圖面配置 | PDF（150 dpi） | PDF、PNG、SVG，解析度較高 |
| 匯出圖徵 | 大部分向量格式，不含 GeoPackage、FlatGeobuf | 全部支援的格式 |
| 中文字型 | 第一次使用時自動下載 | 使用電腦上安裝的字型 |
| Python 外掛、透過 GDAL 讀取的格式 | 不支援 | 支援 |

### 網頁版需要什麼樣的電腦和瀏覽器？

較新版本的 Chrome、Edge、Firefox 或 Safari 都可以。網頁版用 WebGPU 或 WebGL2 繪製地圖，近幾年的電腦、平板和手機都支援。處理幾百 MB 的大型資料時，記憶體較少的電腦可能會比較慢。

### 桌面版在哪裡下載？

到 RustGIS 官方的[安裝說明](https://rustgis.app/installation/)（英文）。Windows 10、11 可以直接從 Microsoft Store 安裝；也可以到 [downloads.rustgis.app](https://downloads.rustgis.app) 下載 Windows、macOS 和 Linux 的安裝檔。桌面版的介面一樣有繁體中文（臺灣）。

## 資料

### 開啟檔案時出現英文訊息，是不是失敗了？

不一定。RustGIS 開啟 ZIP 檔時，會略過它不需要的檔案（例如說明文件），並用英文訊息列出來，這不影響資料本身。只要圖層面板出現新的圖層，就是成功了。詳見[第 2 課](tutorials/02-load-boundaries.md)。

### 開啟 CSV 時說「不是文字檔」，或中文變成亂碼？

多半是檔案用了舊的 Big5 編碼，RustGIS 只讀 UTF-8。先用記事本或 Excel 把檔案另存成 UTF-8 再開啟，步驟見[臺灣範例資料](data/index.md)。

### 為什麼從網址開不了資料？

網頁版從網址讀取資料時，對方的伺服器必須允許網頁跨域讀取（CORS）。很多網站沒有開放，瀏覽器就會擋下來。這時可以先把檔案下載到電腦，再用 **新增資料** 開啟；或改用桌面版。

### 關掉網頁後，資料就不見了嗎？

網頁版不會自動保存。關掉前按 ++ctrl+s++ 把專案存成 `.rgis` 檔，下次用 ++ctrl+o++ 打開就能接著做。網頁版的專案檔會把你載入的資料一起存進去。詳見[第 2 課：儲存專案](tutorials/02-load-boundaries.md#save-project)。

## 匯出與列印

### 匯出的圖片或 PDF 裡，中文字變成空白？

網頁版要先下載中文字型才能畫出中文。地圖上一出現中文字，網頁版就會自動下載，並顯示「正在下載字型」的提示。等地圖上的中文字出現後再匯出就好。

### 地圖上有些縣市的名稱不見了？

RustGIS 會自動避免標註文字重疊。比例尺太小、縣市面積太小時，名稱放不下就會被隱藏。放大地圖或把標註字級調小，就會出現更多名稱。詳見[第 6 課](tutorials/06-export-map.md)。
