# 進階教學

完成[入門教學](index.md)後，可以繼續學這些主題。每一課都可以在網頁版完成。

| 課次 | 內容 | 你會學到 | 狀態 |
|---|---|---|---|
| [7. 鄉鎮人口密度圖](07-choropleth.md) | 用鄉鎮市區界線和人口統計，畫出人口密度圖 | 連結欄位、分級設色、分級法 | ✅ |
| [8. 點位與空間統計](08-points.md) | 把捷運出入口變成點，統計每個行政區有幾個 | XY 表轉點、範圍內彙總、CSV 編碼 | ✅ |
| [9. 國土測繪中心電子地圖](09-wmts.md) | 加入繁體中文的臺灣通用電子地圖和正射影像 | WMTS、資料來源、連線 | ✅ |
| 10. 地形分析 | 用數值地形模型畫出地形陰影和坡度 | 網格、暈渲、坡度 | 撰寫中 |

還沒完成的課程會陸續加上。想先學哪一課，歡迎到 [GitHub](https://github.com/begin0808/RustGIS-TW/issues) 告訴我們。
