# 入門教學

這系列教學用臺灣的行政區界練習 RustGIS 的基本操作。全部都可以在瀏覽器的網頁版完成，不需要安裝任何軟體。

| 課次 | 內容 | 你會學到 |
|---|---|---|
| [1. 開啟網頁版](01-open-web-app.md) | 打開 RustGIS、切換成繁體中文 | 認識畫面各區塊 |
| [2. 載入縣市界](02-load-boundaries.md) | 開啟臺灣縣市界線的 Shapefile | 圖層、坐標參考系統 |
| [3. 屬性表與選取](03-attribute-table.md) | 查看每個縣市的屬性 | 屬性表、依屬性選取 |
| [4. 符號與標註](04-symbols-labels.md) | 依欄位分色、標上縣市名稱 | 符號系統、標註 |
| [5. 環域分析](05-buffer.md) | 畫出臺北市周圍 10 公里的範圍 | 環域、依位置選取 |
| [6. 匯出地圖](06-export-map.md) | 把成果存成圖片 | 圖面配置、匯出 |

## 開始之前

- 準備一台電腦和較新的瀏覽器（Chrome、Edge、Firefox 或 Safari）。
- 下載[臺灣範例資料](../data/index.md)中的「直轄市、縣市界線」。
