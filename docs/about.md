# 關於本站

本站由臺灣的 RustGIS 使用者整理，目的是讓更多人可以用中文學習 GIS。

## 參與貢獻

發現錯字、想補充教學或分享範例資料，歡迎到 [GitHub](https://github.com/begin0808/RustGIS-TW) 開 issue 或 pull request。

RustGIS 介面翻譯的問題，請直接回報到[官方專案](https://github.com/opengeos/RustGIS/issues)，翻譯檔是 `crates/ui-egui/src/i18n/zh-tw.tsv`。
