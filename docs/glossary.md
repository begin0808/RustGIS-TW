## 常見的異體寫法 { #variants }

搜尋本站或資料時，下面這些寫法要注意：

| 本站與 RustGIS 的寫法 | 常見的其他寫法 | 說明 |
|---|---|---|
| 臺北、臺中、臺南、臺東 | 台北、台中、台南、台東 | 內政部資料一律寫「臺」，用「台」會篩選不到 |
| 坐標 | 座標 | 樂詞網用「坐標」 |
| 環域 | 緩衝區 | 臺灣 GIS 教科書與考試用「環域」 |
| 圖徵 | 要素、特徵 | 「要素」是中國大陸用語 |
| 網格 | 柵格、網格資料 | 「柵格」是中國大陸用語 |
| 指北標 | 指北針 | 「指北針」是一般口語 |
